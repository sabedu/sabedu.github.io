---
title: RepoChat
organization: DAS Lab · Concordia University
year: 2025
technologies:
  - Python
  - LangChain
  - Neo4j
  - GitHub GraphQL
  - Streamlit
problem: >-
  Developers and non-technical stakeholders struggle to extract insights from
  GitHub repositories because repository data is spread across commits, issues,
  files, and metadata.
contribution: >-
  Built a web-based chatbot that synergizes LLMs with knowledge graphs to
  translate natural-language questions into graph queries and return repository
  answers.
outcome: >-
  Achieved 90% accuracy on a user study of 40 repository-related questions and
  released an open-source tool and replication package.
links:
  demo: https://repochattool.streamlit.app/
